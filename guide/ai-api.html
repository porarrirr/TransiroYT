AI APIの接続を管理する

設定の「AIサービス」で「APIを追加…」を選び、OpenAI・Anthropic・Gemini・互換APIから種類を選んで、APIキーとモデルIDを設定します。「翻訳に使う」を選ぶと、追加と同時に翻訳の順番の最後に加わります。モデル一覧は取得・検索でき、モデルIDの手入力もできます。接続は16件まで保存できます。

「接続テスト」は短いテスト文を送信し、成功と応答時間、または認証・利用上限・接続先などのエラーを表示します。API利用料金が発生する場合があります。保存前の設定もテストできます。モデル一覧が取れても、推論の利用権限があるとは限らないため、使うモデルで接続テストしてください。

複製では接続先とモデルだけをコピーし、APIキーと使用中の状態はコピーしません。APIのページの「このAPIを削除…」で削除すると、作業の順番からも外れます。変更・削除は設定の「保存」で適用します。未使用の接続はモデル未指定の下書きとして保存できます。

どの作業で使うか

設定の左の一覧で「翻訳」「字幕の言語判定」「訳文の短縮」を選びます。使えるAIが1つの一覧に並ぶので、使うものにチェックを入れ、ドラッグで順番を並べ替えます。上から順に試し、失敗したら次へ進みます。モデル未指定のAPIは選べないため、「設定…」から設定してください。APIのページの「使う作業」でも作業ごとにオン/オフできます。言語判定と翻訳には少なくとも1つ必要です。接続名を変えても割り当ては保持します。

APIキーの保存

キーはこのMacのキーチェーンに保存します。設定ファイルにはキー本体を保存せず、GUI・CLIの設定取得・エクスポートでも返しません。保存済みのキーは入力欄を空のままにすると保持し、「APIキーを削除」を選んで保存すると削除します。Sarashina翻訳のキーは「AIサービス」→「Sarashina翻訳」で管理します。

以前の平文のキーがあれば、設定を読み込むとキーチェーンへ移します。保存・読み取りを確認してから平文の項目を外し、移行に失敗した場合は元のファイルを保持してエラーを表示します。macOSがアクセス確認を表示した場合は、接続に使うキーであることを確認してください。キーチェーンにアクセスできない場合、平文保存には戻しません。

API形式や送信先・モデル一覧の接続先が変わった場合、保存済みキーを自動で引き継ぎません。キーを再入力するか、明示的に削除してください。同じ接続先のURLパスの変更では保持できます。外部APIにはHTTPSが必要です。HTTPはこのMacのlocalhost・127.0.0.1・::1だけに使えます。URLにキーやトークンを入れず、専用欄へ入力してください。

キーチェーンは実行中のアプリのメモリまで保護するものではありません。以前に作成した平文のバックアップや、利用者が別途保存したキー入りインポートファイルも残ります。キーを含むファイルは所有者だけが読める場所に置き、通常の設定エクスポートを移行・共有に使ってください。別のMacにはキーを再入力します。

CLIから使う

transiroyt api list
transiroyt api add MyAPI --url https://example.com/v1 --model model-id
transiroyt api key MyAPI
transiroyt api models MyAPI
transiroyt api test MyAPI
transiroyt api key MyAPI --delete
transiroyt api remove MyAPI

api keyは表示されない入力欄でキーを読み取ります。スクリプトではapi key MyAPI --stdinで標準入力から渡せます。キーをコマンド引数へ書かないでください。名前が重複する場合は一覧のIDで指定します。新しい接続は無効の状態で追加し、設定の作業のページまたは設定JSONで使用先へ割り当てます。

transiroyt config get aiはキーを含まない設定JSONを出力します。config import aiでも接続・モデル・順番を変更できますが、他のMacや複製した接続のキーは別途設定してください。
