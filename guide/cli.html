ターミナルから使う

TransiroYT.appをアプリケーションフォルダへ移して一度起動すると、~/.local/bin/transiroytを登録します。Pythonなどの追加インストールは不要です。既存の同名コマンドがある場合は保持し、アプリのログに記録します。

「command not found」と表示される場合は、次を実行してください。以後のターミナルでも使うには、同じ行を利用中のシェルの設定（zshでは~/.zshrc）に追加してください。アプリはシェル設定を書き換えません。

export PATH="$HOME/.local/bin:$PATH"
transiroyt --help

PATHを変更せず、~/.local/bin/transiroytと指定して実行することもできます。アプリを移動した場合は、移動先のアプリを一度起動すると登録先が更新されます。

吹き替え

transiroyt dub video.mp4 --subtitles video.en.srt -o video.ja.mp4
transiroyt dub 'https://www.youtube.com/watch?v=VIDEO_ID'
transiroyt status
transiroyt cancel JOB_ID

アプリが起動していなければ自動起動します。動画のパスは現在のフォルダを基準に解釈します。字幕は省略可能です。保存先・音量・話者数・画質・生成ステップ数はアプリと同じ設定を使い、オプションで今回だけ変更できます。必要なモデルは自動取得します（停止するには--no-download）。出力の上書きは--overwriteを指定した場合だけ許可します。

既定では完了まで待機し、進捗を標準エラー、結果のJSONを標準出力へ返します。正常終了は0、失敗・中止は非0です。--no-waitは開始したジョブのIDを含むJSONを返して終了します。Ctrl+Cは待機だけを終了し、吹き替えはアプリで継続します。中止するにはcancelを使ってください。アプリは処理中も起動したままにしてください。

同時実行はアプリと共有の1件です。実行中のジョブがある場合、新しい開始要求は拒否します。CLIからGUIの待機キューへの追加はできません。GUIが次のジョブを開始し、待機中のCLIが元の結果を取得できなかった場合は非0で終了するため、ライブラリで完成結果を確認してください。

保存先・音量などの設定

transiroyt config get
transiroyt config set outputDirectory ~/Movies/TransiroYT
transiroyt config set originalVolume 0.25
transiroyt config set dubVolume 1.0
transiroyt config set youtubeQuality 720
transiroyt config set steps 12
transiroyt config set speakers 2
transiroyt config set speakers null

文字列の設定は文字列として、それ以外はJSONとして解釈します。音量は元音声0〜2・吹き替え0より大きく2以下、ステップ数は4〜16、話者数は1〜20またはnull（自動）です。product.jsonをGUIと共有し、次の開始から反映します。開いている設定画面は閉じて開き直してください。

AIの設定

接続の追加・キーの設定・接続テストはAI APIの管理を参照してください。キーはキーチェーンへ保存します。

transiroyt config get ai
transiroyt config set ai.engines.bing true
transiroyt config get ai > ai.json
# ai.jsonを編集してから読み込む
transiroyt config import ai ai.json

AI設定はGUIと同じenabled（作業別指定）、engines、presets、language・translation・shorteningのchainで構成します。chainにはgemmaなどの使用先、APIにはapi:プリセットIDを指定します。プリセットIDは32桁のUUID hexです。get aiの出力を編集する方法で、モデル・URL・順番も設定できます。GUIと同じ入力検査を通し、次のジョブから適用します。

APIキーはgetに含めません。保存済みプリセットと同じID・API形式・送信先なら、api_keyの省略で既存キーを保持し、空文字で削除します。設定する場合はJSONの対象プリセットへ"api_key": "…"を追加してimportします。キー入りファイルは所有者だけが読める場所へ保存してください。config import ai -なら標準入力から読み込めます。

Sarashinaのキーもtransiroyt config import sarashina -へ{"api_key":"…"}を標準入力で渡して設定します。config get sarashinaはキーの有無だけを表示します。通常設定全体のJSONはconfig import product ファイル名で読み込めます。importは対象設定全体の置き換えです。
